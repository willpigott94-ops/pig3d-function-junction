PIG3D - Boundary Road Showroom Model
====================================

2311 Boundary Road, Vancouver. Tenant improvement proposal model, built from
the dys architecture preliminary set (issue 28 Sep 2026).

Contents
  index.html   the model (data, viewer and styles in one file, about 2 MB)

Host it
  Serve index.html from any static web host. No server code, database or
  build step is needed.

Construction timeline
  A scrubber at the bottom of the model runs from the existing building
  (rebuilt from demolition plans A1.01 and A1.02), through Phase 1
  demolition and a clean shell, to the Phase 2 tenant improvement. Items
  removed on the demolition drawings (ceilings, partitions, guardrails and
  handrails, millwork, concrete stairs and ramps, glazing and overhead doors,
  flooring) come out in turn; the new work then goes in. "Show cars" hides
  the parked vehicles so the layout is easier to read. The week numbers are an
  illustrative sequence, not a contractor's programme.

Notes
  - Needs a browser with WebGL 2 (current Chrome, Edge, Firefox, Safari).
  - Fonts load from Google Fonts; offline, the page falls back to system fonts.
  - Drawn from the set: footprint, grids, partitions, raised platform, room
    names and areas. Assumed: heights, roof and finishes. Simplified: doors,
    furniture, vehicles, canopy and the car lot.
